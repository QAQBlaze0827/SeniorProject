# 台灣華語情緒資料集清單

本文件彙整**以台灣華語（國語）為主**的情緒相關資料集，供本專案（4 類：快樂 happy / 憤怒 angry / 悲傷 sad / 平靜 neutral）選用。

- 模態涵蓋：語音情緒、人臉表情、人臉身分、多模態（影音）
- 取得門檻採 ★ 標示（越少越好取得）：
  - ★☆☆☆☆ 可立即下載、免費
  - ★★☆☆☆ 線上註冊後下載、免費
  - ★★★☆☆ 需簽署 EULA / 學術申請
  - ★★★★☆ 需逐一洽作者、無公開下載頁
  - ★★★★★ 付費或授權不明
- 標註語言欄僅描述「標籤/說明文字」與「語音腔調」。

## 8. 風險：語音與臉部準確度不對稱（重要）

### 8.1 風險描述
- **跨語料/跨語言 SER 本就困難**：以對岸華語預訓練、測台灣華語，屬 cross-corpus + cross-lingual，4 類 F1 可能落在 ~45–65%（同語料微調後約 ~60–75%，僅為概略經驗值）。
- **臉部**：TFEID + 預訓練模型接線性頭，4 類受控臉約 ~70–85%，webcam 進階情境會再下降。
- 因此**語音準確度可能明顯低於臉部（落差 10–25 個百分點）**。
- BIIC-Podcast 雖可微調，但其為 **podcast 自發語音**，與本專案近距離互動場景仍有 domain 差。
- 標籤映射（BIIC 主要/次要情緒 + 向度 → 4 類）本身亦帶來損耗。

### 8.2 對融合的影響
- 準確度不對稱**本身不一定崩**，但**未校準 + 簡單平均/concat** 會讓強勢模態（臉部）主導，或讓過度自信的語音機率污染結果，甚至比單模態更差。

### 8.3 緩解設計（逐步導入）
1. **信心加權 late fusion**：以各模態信心（top-1 機率、entropy）動態調整權重。
2. **學習式融合**：在小型 held-out 集上，以兩模態機率向量訓練 meta 分類器（logistic regression / GBM）。
3. **機率校準**：各模態先做 temperature scaling，使機率可比較再融合。
4. **modality dropout**：融合訓練時隨機丟棄一模態，避免過度依賴臉部。
5. **graceful degradation**：語音信心低於門檻時退回「只信臉部」，並於 UI 標示來源。
6. **評估分開報**：臉部 / 語音 / 融合三者各自報告 metrics，以定位落差來源。

### 8.4 後續行動
- 先建立**單模態 baseline** 並量測實際落差，再決定是否導入 weighted / learned fusion。
